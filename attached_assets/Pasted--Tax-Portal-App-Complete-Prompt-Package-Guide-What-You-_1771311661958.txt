## ⚠️ Important Considerations

### **Security First:**

- Never store unencrypted passwords (use bcrypt)
- Always validate file uploads (type, size, viruses)
- Sanitize all user inputs
- Use HTTPS in production
- Keep sensitive data encrypted

### **Mobile Optimization:**

Your users will mostly be on phones:

- Test EVERY feature on mobile
- Optimize touch targets (44px minimum)
- Test signature capture on phones/tablets
- Ensure file uploads work on mobile
- Bottom navbar is crucial for thumb reach

### **Legal Compliance:**

- Privacy Policy is REQUIRED (customize the template)
- Terms & Conditions are REQUIRED
- E-signature consent is REQUIRED (ESIGN Act)
- Audit trails must be kept for 3+ years (IRS requirement)
- Consult with a lawyer before launch

### **Performance:**

- Optimize image uploads (compress before sending)
- Use pagination for message history
- Lazy load documents (don’t load all at once)
- Cache crypto prices (don’t hit API repeatedly)
- Consider CDN for file storage in production

## 📞 When You Get Stuck

### **Debug Strategy:**

1. Check browser console for errors
1. Check network tab for failed API calls
1. Check server logs
1. Test one component at a time
1. Use console.log() liberally

### **Common Issues & Solutions:**

**“Files won’t upload”**
→ Check file size limits, CORS settings, multer config

**“Signatures look weird”**
→ Canvas sizing issue, check viewport settings

**“Emails not sending”**
→ Check SMTP credentials, spam folder

**“Authentication broken”**
→ Check JWT secret, token expiration, localStorage

**“Mobile layout broken”**
→ Test in Chrome DevTools mobile view, check CSS media queries
