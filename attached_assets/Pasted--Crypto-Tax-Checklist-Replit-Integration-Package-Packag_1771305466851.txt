## 🆘 Troubleshooting

**If checkboxes don’t save:**

- Check browser console for localStorage errors
- Ensure site is served over HTTPS (required for localStorage)

**If fonts don’t load:**

- Verify Google Fonts CDN link is intact
- Check internet connection (fonts load from CDN)

**If animations don’t work:**

- Ensure all CSS is intact
- Check for JavaScript errors in console
