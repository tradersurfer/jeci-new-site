# JECI Edge Weekly Newsletter Integration Instructions for Replit Agent

## Overview
Add the JECI Edge Weekly newsletter Issue #1 to the JECI Group website with proper navigation and archive structure.

## Files to Create/Modify

### 1. Create Newsletter Page
**File**: `newsletter-issue-1.html` (or in appropriate directory like `/newsletter/issue-1.html`)
- Use the complete HTML file provided
- Ensure the "Back to Home" link points to your site's homepage
- Update CTA button links to point to actual contact/resources pages on your site

### 2. Create Newsletter Archive/Index Page
**File**: `newsletter.html` (or `/newsletter/index.html`)

Create a newsletter archive page that lists all issues:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JECI Edge Weekly Newsletter Archive | JECI Group</title>
    <!-- Include your site's CSS -->
</head>
<body>
    <!-- Your site's header/navigation -->
    
    <div class="newsletter-archive">
        <h1>JECI Edge Weekly</h1>
        <p class="tagline">Innovate. Optimize. Grow.</p>
        <p>Your no-BS briefing on staying ahead in finances, taxes, and business growth.</p>
        
        <div class="subscribe-cta">
            <a href="https://adrianjordanio.substack.com" class="button">Subscribe on Substack</a>
        </div>
        
        <h2>Newsletter Archive</h2>
        
        <div class="issue-list">
            <div class="issue-card">
                <span class="issue-number">Issue #1</span>
                <span class="issue-date">February 14, 2026</span>
                <h3>Tax Season Alert: 2025 Returns Due April 15</h3>
                <p>Crypto rules tightening + gig worker wins inside. Free tips + your edge starts here.</p>
                <a href="/newsletter-issue-1.html" class="read-more">Read Full Issue →</a>
            </div>
            
            <!-- Future issues will be added here -->
        </div>
    </div>
    
    <!-- Your site's footer -->
</body>
</html>
```

### 3. Update Site Navigation
Add "Newsletter" link to your main navigation menu:
- Link text: "Newsletter" or "JECI Edge Weekly"
- Link URL: `/newsletter.html` (or appropriate path)
- Position: Recommend placing in main nav or footer

### 4. Add Newsletter CTA to Homepage
Consider adding a newsletter section to your homepage:

```html
<section class="newsletter-section">
    <div class="container">
        <h2>📬 JECI Edge Weekly</h2>
        <p>Get weekly tips on tax optimization, bookkeeping best practices, and business growth strategies.</p>

            <a href="/newsletter.html" class="button-secondary">Read Archive</a>
        </div>
    </div>
</section>
```

### 5. Create Resources/Downloads Page (Optional)
**File**: `resources.html`

Create a page where users can download the free resources mentioned in the newsletter:
- Crypto Tax Health Checklist (PDF)
- Profit Leak Detector Worksheet

This page should have a form to capture email addresses before downloads.

## Replit Agent Prompt

Use this prompt with Replit Agent:

```
Add the JECI Edge Weekly newsletter to the website:

1. Create a new file "newsletter-issue-1.html" with the newsletter HTML I'll provide
2. Create a newsletter archive page at "newsletter.html" that lists all newsletter issues
3. Add a "Newsletter" link to the main site navigation
4. Update all CTA button links in the newsletter to point to:
   - Tax Strategy Call → /contact page
   - Resources downloads → /resources page
5. Ensure the newsletter page has a "Back to Home" link
6. Make sure all pages are mobile-responsive
7. Add proper meta tags for SEO

The newsletter should match the site's overall design aesthetic while maintaining its own distinct styling.
```
